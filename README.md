# POS System

A desktop point-of-sale application built with Electron, React, and TypeScript. It brings checkout, inventory, sales reporting, and store administration together in one app.

## Features

- **Checkout:** Search products, scan barcodes, manage a cart, apply discounts, and associate sales with customers.
- **Product and stock management:** Maintain products, categories, and inventory levels.
- **Sales and shifts:** Review sales activity and manage register shifts.
- **Dashboard and reports:** View business summaries, choose report date ranges, and export reports as CSV.
- **Staff accounts and permissions:** Separate admin, manager, and sales-clerk access.
- **Store settings and data tools:** Configure receipt details, create or restore database backups, and review the audit log.
- **Local database:** Store application data in SQLite on the computer running the app.

## Getting started

### Prerequisites

- [Node.js](https://nodejs.org/) and npm
- A supported desktop environment for Electron

### Install dependencies

```bash
npm install
```

### Run in development

```bash
npm run dev
```

### Check types and build

```bash
npm run typecheck
npm run build
```

### Create a distributable

```bash
# Windows
npm run build:win

# macOS
npm run build:mac

# Linux
npm run build:linux
```

Build artifacts are generated by `electron-builder`.

## Project structure

```text
src/
├── main/       Electron main process, database, services, and IPC
├── preload/    Secure bridge between the main and renderer processes
├── renderer/   React user interface
└── shared/     Types shared across processes
drizzle/        SQLite schema migrations
build/          App icons and platform build resources
```
